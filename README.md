PAGINA WEB
Este proyecto es una página web de portafolio personal que hemos desarrollado utilizando tecnologías modernas como HTML5, Bootstrap 4, jQuery y CSS. La estructura de la página está organizada en varias secciones para ofrecer una navegación intuitiva y permitir que los usuarios conozcan mejor a la persona y sus proyectos.

Navbar
La barra de navegación en la parte superior de la página incluye enlaces a diferentes secciones como "About Me", "Projects" y "Contact". Además, incorpora un buscador para encontrar proyectos específicos de manera rápida y eficiente.

Sección "About Me"
Esta sección utiliza un diseño limpio y atractivo con un jumbotron de Bootstrap para presentar la información personal de manera clara y concisa. Es la primera parada para que los visitantes obtengan una visión general de quién eres.

Sección de Estudios
Aquí mostramos la formación académica del usuario mediante tarjetas interactivas. Estas tarjetas tienen un efecto "flip" animado que permite mostrar detalles adicionales al hacer clic en ellas, ofreciendo una experiencia de usuario dinámica y atractiva.

Sección de Proyectos
Presentamos tres proyectos destacados en tarjetas. Al hacer clic en una tarjeta, se despliega un modal que proporciona más detalles sobre el proyecto seleccionado. Esta disposición facilita la exploración de los trabajos realizados y los logros del usuario.

Buscador
El buscador permite a los usuarios encontrar proyectos específicos ingresando términos de búsqueda como "Proyecto 1", "Proyecto 2" o "Proyecto 3". Si el proyecto existe, la página se desplazará automáticamente a la sección correspondiente. Si el proyecto no se encuentra, se muestra un mensaje de error, mejorando la usabilidad de la página.

Formulario de Contacto
Incluimos un formulario de contacto con validación mínima de campos para asegurar que se ingresen los datos necesarios. Al enviar el formulario, se despliega un modal de confirmación que agradece al usuario por su mensaje, completando el ciclo de interacción de manera elegante.

Footer
El pie de página contiene el nombre del desarrollador y el año de creación, proporcionando un toque personal y profesional a la página.

SEGUNDA PARTE DEL PROYECTO
En la segunda parte del proyecto, hemos creado una nueva rama en GitHub llamada parte2 para realizar varias mejoras y adiciones significativas:

Integración de PHP: Hemos añadido PHP a nuestra página web para manejar la lógica del servidor y la interacción con la base de datos de manera más eficiente.

Formulario de Creación de Tablas: Se ha implementado un formulario que permite a los usuarios crear nuevas tablas en nuestra base de datos llamada proyectos. Este formulario facilita la gestión de la base de datos directamente desde la interfaz web.

Corrección de Errores: Hemos corregido los fallos de la entrega anterior siguiendo las observaciones y correcciones proporcionadas por el profesor, asegurando una mejora continua y la calidad del proyecto.

Estas adiciones no solo enriquecen las funcionalidades de la página web, sino que también mejoran su robustez y la experiencia del usuario.
